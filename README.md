# ByteUI

ByteUI is a component library featuring modern UI components, including Neo-Brutalism and standard UI styles for React and Next.js applications.

**npm:** [@explorers_111/byteui](https://www.npmjs.com/package/@explorers_111/byteui)

## CLI Usage

Install and add components directly into your codebase using the `@explorers_111/byteui` CLI:

```bash
# Initialize project configuration
npx @explorers_111/byteui init

# List available components
npx @explorers_111/byteui list

# Add a component to your project
npx @explorers_111/byteui add button
```

## Features

- **Neo-Brutalism & Modern UI Components**: High quality components designed for fast integration.
- **Tailwind CSS Compatible**: Automatically configures styles and CSS variables.
- **Copy & Paste Architecture**: Code is added directly into your project's component directory.

## Repository Structure

- `app/`: Next.js documentation and component preview app.
- `components/`: Component source code.
- `cli/`: Package for the `@explorers_111/byteui` CLI tool.
- `scripts/`: Registry builder scripts (`npm run build-registry`).
